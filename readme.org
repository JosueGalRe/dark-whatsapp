* Dark-WhatsApp (né onyx)
Complete dark mode implementation for [[https://web.whatsapp.com][WhatsApp Web]] with many improvements and
customizable options.

Maintained fork of [[https://github.com/vednoc/dark-whatsapp][vednoc/dark-whatsapp]], rebuilt on the design tokens WhatsApp Web uses today.

[[https://raw.githubusercontent.com/JosueGalRe/dark-whatsapp/master/wa.user.styl][https://img.shields.io/badge/Install%20directly%20with-Stylus-116b59.svg?longCache=true&style=flat]]

#+HTML: </div>

** Features
- Complete recolor through WhatsApp's own =--WDS-*= tokens, popovers included
- Palettes: Nord, Catppuccin Mocha and Latte, Dracula, Gruvbox Dark, Tokyo Night,
  Rosé Pine, plus the original dark blue and dark gray
- Customizable base colors — light/dark color-schemes are supported
- Private mode — blurring contacts and/or chat media until you hover over them
- Compact mode — the chat list collapses to a rail of avatars with unread badges
  and floats over the chat on hover or focus. On at any window width by default;
  =compact_mw= limits it to narrower windows.
- Custom chat background: doodle opacity or your own image
- Custom message bubble, seen icon and system message colors
- Custom emoji opacity and styles for message tails
- App width, UI font, avatar shape, and alerts

** Installation
You have to install [[https://add0n.com/stylus.html][Stylus]] and then click on the install link below.

[[https://raw.githubusercontent.com/JosueGalRe/dark-whatsapp/master/wa.user.styl][https://img.shields.io/badge/Install%20directly%20with-Stylus-116b59.svg]]

All options are in the style's settings in Stylus.

** Getting Started
Set WhatsApp's own theme (Settings > Chats > Theme) to match your palette: dark
for a dark palette, light for a light one. The wordmark and sender name colors
don't go through the tokens and follow that setting.

The login page is left as is. It paints literal colors, and the QR code needs a
light background anyway.

*** When WhatsApp ships an update
=tools/check-tokens.py= compares the theme with WhatsApp's stylesheet and fails
when a token isn't mapped:

#+begin_src sh
curl -o wa.css <url of the stylesheet in the page's link tags>
python3 tools/check-tokens.py wa.css
#+end_src
